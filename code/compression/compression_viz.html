This is an approximation of LZ77, the algorithm behind gzip and deflate. It scans a window of previous text and replaces the longest matching substring with a back-reference (distance, length). A character that has never appeared in the context must be stored literally. Highly structured text — repeated phrases, predictable patterns — compresses to a fraction of its original size. Truly random data cannot be compressed at all.

Kolmogorov complexity K(x) is the length of the shortest program that outputs x. Randomness means K(x) ≈ |x|: no compression is possible. Structure means K(x) ≪ |x|: a shorter description exists. Understanding a thing is finding that shorter description.
