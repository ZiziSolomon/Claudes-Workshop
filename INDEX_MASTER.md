### OPERATIONS & SIMULATION (3 Tools)

**7. taipei-metro-simulator.html** — REAL-TIME OPERATIONS SIMULATOR
- **What it teaches:** Real-time train movements and passenger dynamics
- **Features:** 
  - Adjustable simulation speed (1x-30x)
  - Train count control (5-17)
  - Dwell time adjustment
  - Passenger demand scenarios
  - Live metrics (headway, capacity, efficiency)
- **Time:** 20-30 minutes
- **Outcome:** Understand how system operates in real-time
- **Best for:** Engineers, operators, system planners
- **Part of:** Engineer path (Step 2)
- **Try this:** 
  - Run at 30x speed with 17 trains
  - Observe train spacing and headways
  - Increase demand to peak and watch system respond

**8. taipei-metro-departure-board.html** — LIVE DEPARTURE BOARD SIMULATOR
- **What it teaches:** Real-time train arrivals and crowding
- **Features:**
  - Live departure times
  - Crowding level visualization
  - Station selection
  - Platform assignments
  - Next-train predictions
- **Time:** 10-15 minutes
- **Outcome:** Understand passenger experience and crowding patterns
- **Best for:** Operators, customer service, experience designers
- **Part of:** Engineer path (Step 4)
- **Try this:**
  - Select different stations
  - Watch crowding vary over time
  - Notice pattern changes between peak and off-peak

**9. taipei-metro-capacity-analyzer.html** — CAPACITY STRESS-TESTING TOOL
- **What it teaches:** System capacity limits and stress behavior
- **Features:**
  - Daily demand adjustment (100k-600k)
  - Peak hour concentration control
  - Headway optimization
  - Fleet size control
  - Real-time metrics (load factor, efficiency, health)
- **Time:** 15-20 minutes
- **Outcome:** Understand capacity limits and critical thresholds
- **Best for:** Capacity planners, system designers
- **Part of:** Engineer path (Step 3)
- **Try this:**
  - Set demand to 400k and increase peak concentration
  - Find the breaking point where system degrades
  - Notice how fleet size affects viability

  - Automation level selection
  - Dynamic viability scoring
  - Comparison with reference systems
  - Design recommendations

- **What it teaches:** Revenue, costs, and financial viability

  - Operating cost modeling
  - Capital recovery tracking
  - Real-time profit/loss calculation
  - Payback period analysis
- **Time:** 20-30 minutes
- **Outcome:** Understand financial viability framework
- **Prerequisites:** DESIGN_PRINCIPLES.md Part 2 (Economics)
- **Best for:** Finance planners, business case developers

### ANALYSIS & LEARNING (6 Tools)

**14. taipei-metro-environmental-impact.html** — SUSTAINABILITY CALCULATOR
- **What it teaches:** CO₂ reduction and environmental benefits
- **Features:**
  - Ridership and mode shift control
  - CO₂ avoided calculation (75% vs. cars)
  - Fuel savings computation
  - Economic value of emissions reduction
  - Comparison charts
- **Time:** 15-20 minutes
- **Outcome:** Quantify environmental case for circular lines
- **Best for:** Sustainability planners, environmental advocates
- **Part of:** Planner path (Step 5)
- **Key fact:** 75% less CO₂ per km than private cars

**15. taipei-metro-resilience-analyzer.html** — NETWORK RESILIENCE TESTING
- **What it teaches:** System robustness under disruption
- **Scenarios:**
  - Normal operations (baseline)
  - 10% line delay (operational impact)
  - Single line closure (resilience test)
  - Major disruption (worst case)
- **Features:**
  - Efficiency metrics
  - Alternative route analysis
  - Stranded passenger calculation
  - Comparison: radial vs. circular
- **Time:** 15-20 minutes
- **Outcome:** Understand why circular topology provides redundancy
- **Key finding:** Reduces stranded passengers from 40% → 12%
- **Best for:** System architects, reliability engineers
- **Part of:** Engineer path (Step 5)

**16. circular-metro-quiz.html** — INTERACTIVE LEARNING GAME
- **What it teaches:** Knowledge testing and learning reinforcement
- **Format:**
  - 15 questions across 3 difficulty levels
  - Immediate feedback
  - Explanations for all answers
  - Score tracking
  - Time tracking
- **Time:** 20-30 minutes (initial)
- **Outcome:** Test knowledge and identify learning gaps
- **Best for:** Students, exam prep, self-assessment
- **Part of:** Learner path (Steps 1 & 6)
- **Tip:** Take before and after studying to measure learning
