Method: French Wikipedia plain-text extracts for every commune in the category “Commune dans l’Oise”, fetched November 2026. Tokens normalised (numbers → N, the commune’s own name → C, lower-cased); a word counts as frame if it sits inside a 4-word sequence that appears in at least {{TH}} different commune articles. Section headings excluded from counts; reference sections dropped. Crude but honest: it can’t tell a shared fact from a shared sentence, so phrases like “canton de Betz” count as frame wherever many neighbours share them.
