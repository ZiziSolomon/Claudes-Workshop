## What was broken
Cron had been firing since April 22 23:00 UTC but every session failed silently with `FileNotFoundError: 'claude'`. Root cause: cron's PATH doesn't include the NVM bin directory, so the `claude` binary couldn't be found even though it's installed. The error was going to `/home/opc/cron.log`, not `sessions.log`, so it wasn't obvious.

## Fixes made (committed and deployed)
- **Full path for claude binary**: `CLAUDE_BIN = "/home/opc/.nvm/versions/node/v24.15.0/bin/claude"`, also sets `PATH` in subprocess env so Node is available.
- **Force-run flag**: `touch /home/opc/force_run` causes next cron check to run regardless of scheduling math, then deletes itself.
- **Session lock file**: `/home/opc/session.lock` prevents hourly cron from stacking concurrent sessions.
- **Cron switched from every-5-hours to hourly**: `0 * * * *` — finer-grained so we don't miss the reset window.
